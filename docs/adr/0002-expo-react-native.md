# Use Expo / React Native for cross-platform mobile

The app is built with Expo and React Native rather than Flutter. The team is fluent in TypeScript and has no Dart experience; using React Native avoids the cost of learning a new language and ecosystem. A single codebase ships to both iOS and Android.

## Considered Options

- **Flutter** — strong cross-platform story, but requires Dart. Rejected: unnecessary learning curve given existing TypeScript fluency.
- **Expo / React Native (chosen)** — same TypeScript skills apply, large ecosystem, Expo handles native build complexity out of the box.
