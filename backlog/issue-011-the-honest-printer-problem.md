# Issue 011: The Honest Printer Problem

## Status
Draft Complete

## Inspiration Seed
Kab ibn Malik: truth under pressure when an easy excuse is available.

## Invisible Moral Pattern
A child admits fault instead of hiding behind a believable excuse.

## Child-World Transformation
A team project is missing, everyone blames the printer, but the child knows he forgot to send the file.

## Main Moral Value
Truthfulness.

## Secondary Value
Repairing trust.

## Suggested Setting
Classroom.

## Main Character
Ethan, age 9, imaginative, sometimes forgetful, and brave enough to admit mistakes.

## Supporting Characters
Project teammates, teacher, class helper.

## Natural Humour Idea
The printer makes dramatic noises while producing one blank page.

## Moral Problem
Ethan can let the printer take the blame or tell the truth.

## Resolution Direction
He admits the mistake and works to fix the project.
